29   ## Overview 
30    
31   This notebook demonstrates a complete workflow for validating SAOCOM InSAR height measurements against two reference Digital Elevation Models (DEMs): 
32   - **TINItaly DEM** (10m resolution, high accuracy) 
33   - **Copernicus DEM** (30m resolution, global coverage) 
34    
35   ### Analysis Steps: 
36   1. Load and preprocess SAOCOM point cloud data 
37   2. Resample reference DEMs to common resolution (10m) 
38   3. Sample reference DEM heights at SAOCOM point locations 
39   4. Calibrate SAOCOM relative heights to absolute heights 
40   5. Detect and remove outliers using machine learning 
41   6. Perform statistical analysis of height differences 
42   7. Analyze performance by land cover type 
43   8. Generate comprehensive visualizations 
44    
45   ### Key Concepts: 
46   - **InSAR Heights**: SAOCOM provides *relative* heights that require calibration to a reference 
47   - **Coherence**: Quality metric for InSAR measurements (0-1, higher is better) 
48   - **NMAD**: Normalized Median Absolute Deviation, a robust accuracy metric 
49   - **Outliers**: Anomalous measurements detected using Isolation Forest algorithm
